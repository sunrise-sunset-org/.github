# Sunrise-Sunset.org

Sunrise, sunset, twilight and moon times for any place on Earth, at [sunrise-sunset.org](https://sunrise-sunset.org).

- **Free API**, no key needed: [documentation](https://sunrise-sunset.org/api) · [examples and spec](https://github.com/sunrise-sunset-org/api)
- **MCP server** for AI assistants (Claude, ChatGPT, Cursor, Codex): [setup](https://sunrise-sunset.org/mcp)
- **API changes**: watch our [releases](https://github.com/sunrise-sunset-org/api/releases) to be notified
- Found a problem with the API? [Open an issue](https://github.com/sunrise-sunset-org/api/issues/new/choose)
